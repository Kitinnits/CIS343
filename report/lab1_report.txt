-------------------------
Lab 1 Report
-------------------------

My language is called "language" because it doesn't require a 
complex name to function. 

--------------
Regex
--------------

Number literals - [0-9]+ (\.[0-9]+)?
String literals - "[^"]*"
Identifiers - [a-zA-Z_0-9]+

---------------
Design Choices
---------------

I followed most of the design choices that lox followed,
but I changed the keywords fun and nil to def and none
respectively because I am more familiar with them.

---------------
Setup Instructions
---------------

The language is self-contained and does not require any dependencies.

To run the program in repl mode, run "python src/language.py".
to read a file using the program, run "python src/language.py <filepath>
to run the test file, run "python src/language.py test/lab1/lab1_test.txt"

----------------
Test results
----------------

The test file tests every token type, and every error that the scanner can handle.
The output outputs the errors of unrecognized characters at line 23 and unterminated string at line 27.
The numeric boundary case test within the test file shows that the "." character is treated as an operator
in these cases.
